# Woodstove 2

Браузерний 3D-конфігуратор дров'яної печі з оціночним розрахунком і виробничими
документами. Живе посилання: https://olehcheff.github.io/woodstove2/

## Для кого

- **Передусім — для тих, хто будує піч сам** (зварювальник, майстер): задати габарити,
  дверцята й матеріали, подивитися 3D-модель, отримати специфікацію (BOM), розкладку деталей
  для різу (DXF) і креслення.
- **Також — швидкий підбір за приміщенням:** вказати призначення (сауна / кімната / майстерня)
  та обʼєм (або площу × висоту стелі) — застосунок оцінить потрібну потужність і підбере габарити.

## Що вміє

- **3D-модель печі** (three.js): корпус, шамот, ізоляція, дверцята, бафль, повітряні канали,
  димохід; вигляди: розріз, теплові зони, потоки повітря, дим, розбирання. Колір і матеріали регулюються.
- **Автопроєктування:** користувач задає лише зовнішні габарити, дверцята й матеріали; бафль, отвори,
  канали, ізоляція та димохід підбираються автоматично під максимум ККД. Є десять готових
  моделей WS-1…WS-10 за потужністю й п'ять режимів роботи (start-up, low, medium, high, overnight).
- **Оціночна фізична модель:** ККД, потужність, час горіння закладки, тяга, температури, надлишок
  повітря, попередження. Модель стаціонарна (без розпалу й догоряння як окремих фаз).
- **Валідація геометрії** (дверцята, бафль, отвори, шамот, димохід) та оптимізатор бафля.
- **Специфікація й документи:** BOM з масою, площею різу й довжиною швів (CSV, 11 колонок, uk/en),
  DXF розкладки сталевих деталей, технічне креслення SVG з допусками й символами швів,
  експорт 3D у GLTF і STL, знімок екрана, друк/PDF-звіт.
- **Журнал Test Burn і калібрування:** результати власних випалів зберігаються в журналі (CSV-експорт),
  за ними модель калібрується з демпфуванням.
- **Порівняння** поточної конфігурації зі збереженою, **посилання «Поділитися»** (`#config=…`),
  збереження/завантаження конфігурації у JSON; стан зберігається в `localStorage` браузера.
  Калібрування особисте: ні посилання, ні JSON-файл його не переносять (файл його не містить, з посилання
  воно відкидається з повідомленням); відновлюється з журналу кнопкою «Калібрувати з журналу».
  Відкрите з посилання піч одразу зберігається як поточний проєкт; попередній повертає «Скасувати» (9 с).
- **Мови:** українська та англійська (`?lang=en`).

## Чесні обмеження

- Усі результати — **оцінки**, а не CFD і не сертифікація. Константи моделі позначені як оцінки
  (див. розділ 7 у [REPORT.md](REPORT.md)); вимірювань власника для них поки немає, тож числа
  калібруйте власним Test Burn.
- Специфікація, розкладка й креслення — довідкові; перед різом і зваркою перевіряйте розміри самі.
- **Питання монтажу, безпечних відступів до горючих матеріалів, вимог до димоходу та місцевих
  норм застосунком поки НЕ охоплені** (заплановано як окрема фаза, див. [docs/ROADMAP.md](docs/ROADMAP.md)).
  Не вважайте результат дозволом на встановлення: це питання до чинних норм і фахівця.
- Для 3D потрібен WebGL; three.js підвантажується з CDN, тож потрібен інтернет.

## Запуск

Збірки немає: це статичні файли з ES-модулями.

```bash
npm ci                # один раз: ESLint
npm run serve         # npx serve . → відкрити index.html у браузері
npm run check         # ESLint + тести (node tests/physics.test.js) — перед кожним пушем
                      # ≈15 с на вільній машині; на завантаженій — до кількох хвилин (годинникових перевірок немає)
npm run smoke         # опційно: headless-браузер (Playwright), без нього друкує SKIPPED
npm run bench         # опційно: вимірювання часу підбору під приміщення (не входить у check)
```

Потрібен Node 20 або новіший (у CI — Node 22). Деплой — GitHub Pages з гілки `main`.

## Структура

```
woodstove2/
├── index.html            # сторінка, importmap для three.js
├── css/styles.css
├── js/
│   ├── app.js            # сцена, UI, креслення, журнал, експорт, керування
│   ├── config.js         # конфіг за замовчуванням, normalize, валідація, пресети, share-посилання
│   ├── physics-model.js  # оціночна фізика (PhysicsModel), оптимізатор бафля
│   ├── autodesign.js     # автопроєктування внутрішньої геометрії
│   ├── room.js           # потрібна потужність приміщення і підбір габаритів
│   ├── stove-builder.js  # побудова 3D-геометрії
│   ├── bom.js            # специфікація, CSV, SVG-креслення, DXF
│   ├── production.js     # допуски, теплові зазори, символи швів
│   ├── calibration.js    # калібрування за журналом Test Burn
│   ├── exporters.js      # експорт GLTF/STL
│   └── i18n.js           # словники uk/en
├── tests/                # physics.test.js (npm test), bench.mjs, smoke.*.mjs
├── docs/                 # ROADMAP.md, QA-звіт, archive/ (старі промпти перевірки)
├── REPORT.md             # технічний звіт: модель, тести, відомі обмеження
└── AGENTS.md             # правила змін
```
