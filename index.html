        Тур по Woodstove 2

        1. Бафль — подовжує шлях газів, піднімає догорання. Контролюй висоту/кут/зазор.
        2. Air-wash — щілина над склом + приток. Вузька щілина + сильний вогонь = кіптява.
        3. Режими — пресет повітря і полум'я. Фізика v3 враховує площі каналів і підігрів.
        4. Креслення — front/side/top з SVG-розмірами. Камера фіксується.
        5. Експорт — GLTF/STL для виробництва, JSON — для обміну конфігом.
